# MetaBalbes

Здесь можно скачать установщик и обновления MetaBalbes. Исходников программы в этом репозитории нет.

## Установка и обновление

Скачайте `MetaBalbes-Setup.exe` со страницы [последнего выпуска](https://github.com/DieRichX/MetaBalbes-Updates/releases/latest) и запустите его. При повторной установке программа обновится в той же папке. Профили и макросы хранятся отдельно и сохраняются.

Проверить обновления можно в разделе «Информация» самой программы. Версию программа сверяет с небольшим файлом `latest.json`, а перед установкой проверяет контрольную сумму. Если новая версия не запустится, установщик вернёт прежние файлы.

## Профили и резервные копии

В меню профиля можно вернуть удалённый профиль, восстановить данные из резервной копии или сохранить все профили в один ZIP-файл. Архив удобно перенести на другой компьютер.

В каждом выпуске есть установщик `MetaBalbes-Setup.exe` и файл `MetaBalbes-Setup.exe.sha256` для проверки загрузки.
