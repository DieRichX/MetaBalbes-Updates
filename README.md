# MetaBalbes

Здесь можно скачать установщик и обновления MetaBalbes. Исходников программы в этом репозитории нет.

## Установка и обновление

Скачайте `MetaBalbes-Setup.exe` со страницы [последнего выпуска](https://github.com/DieRichX/MetaBalbes-Updates/releases/latest) и запустите его. При повторной установке программа обновится в той же папке. Профили и макросы хранятся отдельно и сохраняются.

Проверить обновления можно в разделе «Информация» самой программы. Перед установкой она проверит файл. Если обновлённая версия не запустится, установщик вернёт предыдущие файлы.

## Профили и резервные копии

В меню профиля можно восстановить удалённый профиль, вернуть его данные из резервной копии или сохранить все профили в один ZIP-файл. Такой архив удобно перенести на другой компьютер.

В каждом выпуске есть установщик `MetaBalbes-Setup.exe` и файл `MetaBalbes-Setup.exe.sha256`. Программа использует его, чтобы проверить загрузку.
