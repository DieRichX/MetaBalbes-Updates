# MetaBalbes

Здесь размещаются установщик и обновления программы. Исходного кода здесь нет.

## Установка и обновление

Скачай `MetaBalbes-Setup.exe` из [последнего релиза](https://github.com/DieRichX/MetaBalbes-Updates/releases/latest) и запусти его. Если MetaBalbes уже установлена в эту папку, установщик заменит файлы программы. Макросы и профили хранятся отдельно и останутся на месте.

Проверить новую версию можно из раздела «Информация» в самой программе. Перед установкой приложение сверяет контрольную сумму файла. Если новая версия не запустится, прежние файлы будут восстановлены.

## Файлы релиза

В каждом стабильном релизе находятся установщик `MetaBalbes-Setup.exe` и его контрольная сумма `MetaBalbes-Setup.exe.sha256`. Она нужна приложению для проверки загрузки.
